# Imagens dos memes

Coloque nesta pasta 4 imagens com estes nomes (pode ser .jpg, .jpeg, .png ou .webp):

| Arquivo        | Quando aparece |
|----------------|----------------|
| `sorriso.jpg`  | Sorriso grande ou sinal de paz (macaco sorrindo) |
| `pensando.jpg` | Olhar para cima / pensando, e imagem padrão (macaco pensando) |
| `joinha.jpg`   | Joinha (macaco fazendo joinha) |
| `timeout.jpg`  | Gesto de timeout, o T com as duas mãos |

Se alguma imagem estiver faltando, o MemeCV continua rodando e mostra um aviso no lugar dela.
